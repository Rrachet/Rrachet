## 🚀 Flagship: AIBOT

**AI-powered lead conversations, follow-ups and sales workflow platform.**

AIBOT demonstrates end-to-end software engineering:

```text
LEAD → AGENT → CAMPAIGN → CONVERSATION
                         ↓
                    OUTCOME
                         ↓
              FOLLOW-UP → WHATSAPP
                         ↓
                    ANALYTICS
```

### Engineering highlights

- Next.js App Router + TypeScript + React
- Supabase + PostgreSQL
- Multi-tenant workspace architecture
- PostgreSQL Row Level Security
- Email/password authentication + PKCE
- REST API routes and server-side authorization
- AI conversation engine with deterministic demo providers
- Provider abstractions for future AI, voice and messaging integrations
- Browser speech preview in English, Hindi and Hinglish
- Zemo contextual product copilot
- CSV / Excel lead ingestion
- Analytics and durable conversation records
- Regression, browser, typecheck and production-build verification
- Deployed on Vercel

**Live:** https://aibot-amar-proj.vercel.app  
**Code:** https://github.com/Rrachet/AIBOT
