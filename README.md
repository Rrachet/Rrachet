## Selected Systems

### LaunchPad — Full-Stack Application

**React · Node.js · Express · PostgreSQL · Prisma · OAuth · OTP**

A full-stack platform built around real authentication and relational application workflows.

- Layered Express backend with routes, controllers, middleware, services and utilities
- PostgreSQL relational data model through Prisma
- Password authentication, verification workflows and Google OAuth
- Email OTP workflow and authenticated application flows
- React frontend with REST API integration and data visualisation
- Deployment-oriented frontend/backend configuration

**Repository:** https://github.com/Rrachet/LaunchPad

---

### Gun2Gun — AI LiveOps & Game Design Workbench

**TypeScript · React · Express · Gemini 2.5 Flash · Recharts**

A domain-specific AI application that turns game context into structured LiveOps and game-design outputs.

- Server-side LLM integration rather than exposing provider credentials in the client
- Task-specific AI workflows for LiveOps concepts, GDDs, quests and economy analysis
- Express API boundary between the product UI and model provider
- Prompt orchestration based on the requested operation
- Analytics-oriented UI for presenting generated game-design insights

**Repository:** https://github.com/Rrachet/Gun2Gun

---

### TwoFold — Android Task Management

**Kotlin · Jetpack Compose · Room · Retrofit · Coroutines · Firebase**

A native Android task-management application using modern Android development patterns.

- Declarative UI with Jetpack Compose and Material 3
- ViewModel/state-driven application architecture
- Room-based local persistence
- Retrofit/OkHttp networking
- Kotlin Coroutines for asynchronous operations
- Automated testing infrastructure including Robolectric, Compose tests and Roborazzi

**Repository:** https://github.com/Rrachet/TwoFold--App-for-Task-management
